YouTube API key

Needed to load the top videos. Free, stored only in this browser.

  1. Open console.cloud.google.com and create a project.
  2. Go to APIs & Services → Library, find YouTube Data API v3, and click Enable.
  3. Go to Credentials → Create credentials → API key.
  4. Edit the key: under Application restrictions pick Websites and add your site's address, and under API restrictions pick YouTube Data API v3. This stops others from using your key.
